# 🎓 Проєкт "Університет Каразіна": Система обліку наукової діяльності

Даний проєкт реалізований у межах практичних робіт з курсу "Бази даних". Він присвячений розробці реляційної моделі на базі **T-SQL** для автоматизації моніторингу наукових здобутків викладачів Харківського національного університету імені В. Н. Каразіна.

## 📋 Опис предметної області
База даних розроблена для відстеження наукової активності кафедр. Вона дозволяє вести облік:
* **Кафедр та факультетів**: організаційна ієрархія університету.
* **Співробітників**: викладацький склад із зазначенням посад (від асистента до професора).
* **Наукових праць**: публікації вчених, їх імпакт-фактори та рівень цитованості.

---

## 🏗 Фізична модель бази даних
Проєкт базується на трьох основних сутностях:
1.  **Departments** (Кафедри) — містить назву та приналежність до факультету.
2.  **Employees** (Співробітники) — персональні дані, посади та прив'язка до кафедр.
3.  **Publications** (Публікації) — наукові роботи, рік видання, показники впливу (Impact Factor) та кількість цитувань.



---

## 🛠 Технологічний стек
* **СУБД**: Microsoft SQL Server (T-SQL)
* **Інструменти**: SQL Server Management Studio (SSMS)

---

## 📂 Опис файлів проєкту

### 1. `INSERT.SQL`
Цей файл містить повний скрипт для розгортання середовища:
* Створення бази даних `KarazinUniversity`.
* Визначення таблиць із забезпеченням цілісності даних (Primary & Foreign Keys).
* **Генерація 100 записів** публікацій за допомогою циклічних скриптів T-SQL для створення реалістичного масиву даних.

### 2. `QUERY.SQL`
Збірка аналітичних запитів (Завдання 3–11), що демонструють:
* Складні фільтрації за допомогою `WHERE`, `LIKE`, `AND/OR`.
* Багатотабличні об'єднання через `INNER JOIN` та `LEFT JOIN`.
* Статистичну обробку даних за допомогою `GROUP BY` та `HAVING`.
* Використання вкладених запитів (`SUBQUERY`) для ідентифікації наукових лідерів.

---

## 🚀 Інструкція із запуску
1. Скопіюйте вміст `INSERT.SQL` у вікно запитів вашої СУБД та виконайте його (`F5`).
2. Після успішного створення таблиць використовуйте `QUERY.SQL` для перевірки виконання завдань.
